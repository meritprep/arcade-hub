# Arcade Hub

A small browser arcade with games that run locally in the page—no third-party game assets or proprietary game code are bundled.

## Games

- Aim Rush, Dodge, Clicker, Snake, Tic Tac Toe, and Reflex
- **Metro Dash**, an original lane-dodging endless runner inspired by classic arcade mechanics
- Brick Breaker

Metro Dash is not Subway Surfers and does not use its name, artwork, music, characters, or other assets. If adding third-party games in the future, verify the repository's license first, preserve attribution, and avoid hotlinking untrusted scripts or frames.

Run locally with any static web server, or visit the deployed site: https://arcade-hub-nine-zeta.vercel.app
